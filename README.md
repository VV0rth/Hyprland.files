<h1>Linux Desktop &amp; Dotfiles</h1>
<p>Personal configuration for a CachyOS desktop centered on <strong>Hyprland</strong>, with a coordinated terminal, shell, editor, and desktop UI setup. The files here cover both day-to-day workflow and the visual details that tie the environment together.</p>
<blockquote>
<p><strong>Status:</strong> This directory contains the configs described below. Adapt machine-specific paths, monitor names, packages, and commands before using it on another system.</p>
</blockquote>

<p>| Area | Configured tools | What lives here |

<h2>Desktop environment</h2>
<h3>Hyprland</h3>
<p>The Hyprland setup is organized as Lua modules under <a href="hypr/"><code>hypr/</code></a>, with <code>hyprland.lua</code> loading the pieces. The configuration sets <strong>Super</strong> as the main modifier and separates behavior into focused modules:</p>
<ul>
<li><code>hypr/config/</code> — animations, autostart, colors, decorations, defaults, environment, input, keybinds, monitor configuration, variables, and window rules.</li>
<li><code>hypr/dms/</code> — DankMaterialShell-related binds, colors, cursor, layout, outputs, and window rules.</li>
<li><code>hypr/hyprlock.lua</code> and <code>hypr/hyprlock.conf</code> — lock-screen configuration.</li>
<li><code>hypr/monitors.lua</code> and <code>hypr/workspaces.lua</code> — monitor and workspace helpers.</li>
<li><code>hypr/scripts/</code> — screenshot, area capture, and full-screen capture helpers.</li>
</ul>
<p>The current monitor module names <code>DP-1</code> and <code>HDMI-A-1</code>, each at 3440×1440 and 100 Hz. The default applications include Kitty, Zen Browser, Nautilus, and Rofi. Keybinds cover launching apps, window focus and movement, floating/fullscreen/group operations, resizing, workspace navigation, media/volume, brightness, and screenshots. Autostart launches DMS, a volume OSD pipeline, the Polkit agent, session environment setup, idle handling, and Google Messages.</p>
<p>The Lua files are marked as generated by <code>hyprlang2lua</code>; review them alongside the installed Hyprland and Lua integration before changing or reloading the configuration. Some modules and commands rely on local packages and session services.</p>
<h3>DankMaterialShell and Quickshell</h3>
<ul>
<li><a href="quickshell/"><code>quickshell/</code></a> contains the Quickshell/DankMaterialShell source tree, including bar, dock, control center, notifications, lock screen, settings, and other desktop modules.</li>
<li><a href="hyprpanel/"><code>hyprpanel/</code></a> contains a separate HyprPanel configuration and module preferences.</li>
<li><a href="DankMaterialShell/"><code>DankMaterialShell/</code></a> contains local DMS themes and plugins.</li>
<li><a href="matugen/"><code>matugen/</code></a> contains templates used to generate coordinated colors for Hyprland and other applications.</li>
</ul>
<p>These folders include substantial application or upstream source/config content. The README describes their presence, not a claim that every file is a small personal override.</p>
<h2>Terminal, shell, and editor</h2>
<h3>Kitty</h3>
<p><a href="kitty/kitty.conf"><code>kitty/kitty.conf</code></a> uses <strong>JetBrains Mono Nerd Font</strong> at 11 pt, a translucent background, a beam cursor with trail, and a powerline tab bar. It starts Fish, adds custom copy/interrupt behavior, provides search bindings, and maps keys for scrolling and font-size changes. Theme and tab styling live in <code>kitty/dank-theme.conf</code> and <code>kitty/dank-tabs.conf</code>; <code>scroll_mark.py</code> and <code>search.py</code> are helper scripts.</p>
<h3>Fish and Starship</h3>
<p><a href="fish/config.fish"><code>fish/config.fish</code></a> sources CachyOS's Fish configuration, conditionally loads Pywal colors, adds local tool directories to <code>PATH</code>, and initializes Drift. Personal functions are in <code>fish/functions/</code> and completions in <code>fish/completions/</code>.</p>
<p><a href="starship.toml"><code>starship.toml</code></a> defines a compact, color-segmented prompt using environment-provided colors. It includes OS, username, directory, Git state, command duration, and language/tool symbols. Fish's Starship initialization is currently commented out in <code>config.fish</code>.</p>
<h3>Neovim</h3>
<p>The <a href="nvim/"><code>nvim/</code></a> directory is a <strong>LazyVim starter configuration</strong> bootstrapped through <code>lazy.nvim</code>:</p>
<ul>
<li><code>init.lua</code> loads <code>config.lazy</code>.</li>
<li><code>lua/config/</code> contains plugin bootstrap, options, keymaps, and autocommands.</li>
<li><code>lua/plugins/</code> contains colorscheme and transparency overrides, Dank colors, and the example plugin file.</li>
<li><code>colors/</code> and <code>lua/lualine/themes/</code> provide custom DMS color integrations.</li>
<li><code>lazy-lock.json</code> records plugin revisions; <code>stylua.toml</code> configures Lua formatting.</li>
</ul>
<p>Tokyo Night is configured with transparency enabled. Lazy.nvim checks for plugin updates periodically without notifications and disables a few built-in runtime plugins.</p>
<h3>Alacritty and tmux</h3>
<p><a href="alacritty/"><code>alacritty/</code></a> contains a second terminal configuration. <a href="tmux/tmux.conf"><code>tmux/tmux.conf</code></a> enables mouse support and uses a transparent/default status background.</p>
<h2>Documents and system appearance</h2>
<h3>Zathura</h3>
<p><a href="zathura/zathurarc"><code>zathura/zathurarc</code></a> enables recoloring, transparent page backgrounds, and adjusts opened documents to fit the window width.</p>
<h3>GTK and Qt</h3>
<ul>
<li><code>gtk-3.0/</code> and <code>gtk-4.0/</code> — GTK appearance preferences; GTK4 currently prefers a dark theme, Fira Sans, and Capitaine cursors.</li>
<li><code>qt5ct/</code>, <code>qt6ct/</code>, <code>Kvantum/</code>, and <code>qt5ct/colors/</code> — Qt appearance and theme settings.</li>
<li><code>environment.d/</code> and <code>xdg-desktop-portal/</code> — session environment and portal preferences.</li>
</ul>
<h3>Other configured applications</h3>
<p>Additional folders include <code>btop/</code> (system monitor), <code>fuzzel/</code> (launcher), <code>fcitx5/</code> (input method), <code>wireplumber/</code> (audio), <code>ncspot/</code> (terminal music client), <code>vlc/</code>, and various application-specific settings. Their presence can vary over time; browse the folders for the current options.</p>

<h2>Portability notes</h2>
<ul>
<li>Review monitor names and resolutions in <code>hypr/</code> for your hardware.</li>
<li>Several commands, paths, and startup services are specific to this machine or CachyOS; install the corresponding programs or adjust those entries first.</li>
<li>Colors are shared/generated across applications. Look at <code>matugen/</code>, <code>hypr/</code>, and Kitty theme files when changing the palette.</li>
<li>Runtime state and caches are not useful dotfiles. Keep browser profiles, databases, logs, and other machine-generated state out of a public repository.</li>
</ul>
